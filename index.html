Bulk Import Tracking CSV

Expects a "Shipment Ref#" column (matches PO/Order Number) and a "Tracking No" column — the same format your 3PL's Order QueryBy Order export uses. Multiple rows sharing a Shipment Ref# (multi-package orders) get combined into one tracking value automatically.

Mass Upload Orders

One row = one order, address entered once. Sending more than one product to the same person? List it on that same row under "SKU 2"/"Qty 2", "SKU 3"/"Qty 3", and so on — not a separate row — so it stays one order/PO instead of looking like two. Need more than 5 products on one row? Just add "SKU 6"/"Qty 6" columns yourself, it'll be picked up automatically.
Downloads as a color-formatted .xlsx — the highlighted columns are where you type, the columns on the right are the full valid-SKU list for reference (ignored on upload, no need to delete them). Fill it in and upload it right back on this tab, .xlsx or .csv both work.
The sheet doesn't carry a per-row shipping speed, so one speed applies to every order in this upload.
.xlsx/.xls upload fine as-is — any colors/formatting you've added in Excel are ignored, only the cell values matter.
